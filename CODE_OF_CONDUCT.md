# Code of conduct

This is a small project. The aim is for it to stay friendly and useful to everyone who uses it or helps with it.

## What I expect

- Be respectful, and assume good faith.
- Talk about the work, not the person. Disagree with the idea, not the one who had it.
- Keep issues and pull requests on topic.

## What is not acceptable

- Harassment, insults, personal attacks or discrimination.
- Publishing someone else's private information.
- Spam, or anything unlawful.

## What happens

The maintainer can edit or remove comments, close or lock issues and pull requests, and block people from the repository. This applies to everything in the repository: issues, pull requests, discussions and review comments.

## Reporting

To report a conduct problem privately, open the **Security** tab of this repository, choose **Report a vulnerability**, and start the title with "Conduct:". Only the maintainer can see it. Please allow about a week for a reply, as this is maintained in spare time. If the report is about the maintainer, you can contact [GitHub Support](https://support.github.com).
